# Jev 辅助上下文压缩：实验方案与首轮结果

日期：2026-10-08。状态：输入修复采用；Jev 保留为可选实验，默认关闭。

## 实验问题

在完整历史仍提供给摘要模型的前提下，Jev 的重要性标记能否减少关键事实遗漏？将基础输入修复与 Jev 收益分开比较。

## 冻结方案

- 数据：6 个人工会话，覆盖用户约束、工具元数据、决策修正、审批阻塞、中文约束及计划/结果区别。每组首轮重复 1 次。
- 数据 SHA-256：`c9035699fb922356e11cfd2c30d6c6502b6f733a50bad859a34fd6ea6300aafa`。源文件：`scripts/fixtures/jev-cases.ts`。
- 三组：legacy（原 role/content 输入与原提示词）、full-transcript（完整消息 JSON 与修正提示词）、jev-assisted（与第二组相同，增加重点原文）。因此第一、第二组之间是组合修复，不能单独归因给序列化。
- 摘要模型：`deepseek/deepseek-v4-flash`；本次 Jev 实际返回 `jev-1.13.0`。摘要统一要求最多 120 个词；每次模型请求最多等待 45 秒。
- Jev：一条消息一个 Score，单次批量请求；score ≥ 2 且 confidence ≥ 0.6，最多标记 4 条。这个阈值是试验策略，不是已校准的准确率保证。
- Jev 预算：最多 24 条旧消息、完整输入最多 32,000 字符；超预算、缺密钥、无效结果或服务错误回退。交互默认超时 5 秒，试验为 15 秒，无自动重试。
- 首轮预算：最多 36 次 DeepSeek 请求（18 次摘要、18 次探针）与 6 次 Jev 请求。另运行 1 次真实插件链路冒烟。

## 指标与结果

| Arm | Completed | Fact recall | Probe recall | Mean summary ms | Mean token ratio | Jev fallbacks |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| legacy | 6/6 | 15/17 | 18/19 | 1669 | 0.292 | 0 |
| full-transcript | 6/6 | 16/17 | 19/19 | 1604 | 0.464 | 0 |
| jev-assisted | 6/6 | 16/17 | 19/19 | 1982 | 0.443 | 0 |

Fact recall 为摘要中大小写不敏感的原文子串命中；Probe recall 为仅依据摘要回答固定问题时的子串命中。两者都不是语义正确率或真实任务完成率。token ratio 为摘要/原消息的启发式估算，不是实际 tokenizer 计量。

人工复查：legacy 的工具测试样本未保留完整验证命令，探针无法还原；修复组及 Jev 组均保留该命令。三组摘要中未出现字面工具名 shell 的情况造成部分 fact 未命中，不能简单解释为任务失败。其余固定问题仍需防范子串匹配遗漏否定、纠正与同义表述。

Jev 6 次调用全部返回有效结果，无回退；其中 3 次选出重点、3 次未通过选取阈值。相对修复组，Jev 组事实/探针命中相同，平均摘要耗时增加约 24%，摘要 token 比例略小。6 个样本及单次重复不足以证明效果提升。

Jev 用量记录在原始结果中；DeepSeek 的实际 token 用量、总 API 成本及端到端任务完成情况未计量。不能据此宣称成本下降或任务成功率提升。

## 采用与未采用

- 采用：完整工具名称、参数、关联 ID 纳入摘要输入；明确计划与结果的提示词；摘要取消和空摘要保护。
- 完成：Jev off/shadow/assisted 三种模式、保守重点标记、超时与无效结果回退、观察记录。事件存储、区间边界及工具配对仍由代码控制；不根据分数删除消息。
- 未采用：默认启用 Jev。保留 `TINY_DSH_JEV_MODE=off`；不根据这 6 个样本调低阈值以追求更好成绩。

## 复现


## 后续晋级门槛

另建至少 20 个未参与提示词/阈值修改的会话，固定模型版本并每例重复 3 次。人工审核关键约束、纠正与未解决问题；相对修复组要求关键事实保留率提高至少 5 个百分点，探针语义正确率不下降，用户约束不得新增遗漏；摘要平均耗时增长不超过 30%、token 比例增长不超过 10%。所有协议、取消、回退测试通过后才考虑默认启用。若修复组已接近满分，应扩展更困难的任务而不是在此小集上调参。

118 项行为测试通过，typecheck 与 lint 通过；真实插件冒烟完成 1 个检查点，保留全部原始事件和工具配对，投影为 3 条消息。该冒烟中 Jev 返回 no-selection，验证了无重点时的正常摘要链路。交互式 pnpm start 已验证页头、/help、/new、/exit、真实 read_file 往返与空闲 Ctrl+C 退出；无网络 mock 场景验证了审批等待 Ctrl+C 取消、回到提示符且保留 1 条配对工具结果。
